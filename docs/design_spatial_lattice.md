# The spatial-type lattice, formalized

The spatial analysis ([SpatialTypes.scala](../src/main/scala/SpatialTypes.scala)) abstracts a
`Space` as a **length-indexed count domain**. This document enumerates every property the
implementation *relies on*, states the laws we believe hold, and records which are **machine-certified**
in [`proofs/spatial/`](../proofs/spatial) (generated by
[gen_spatial_obligations.py](../scripts/gen_spatial_obligations.py); each file asserts the NEGATED
theorem, so z3 `unsat` / vampire `Refutation found` = PROVED and z3 `sat` = COUNTERMODEL).

The point is not to record trivia. Three of these laws *changed the code*: the `⊥` countermodel
corrected the lattice's bottom, and the subsumption + self-restriction families became a new
relational layer that measurably tightens the analysis (§6).

---

## 0. The standing invariant: no evaluation

An abstract interpretation **strictly propagates annotated (spatial) types**. None of the three
analyses may call `eval`/`evalI`/`evalT` on a subterm: a bound obtained by running the program is an
evaluation result, not an inferred one, and reporting it as an inferred bound misrepresents what the
analysis knows. Precision therefore has exactly three legitimate sources — the term's own syntax
(literals, path constants, `Range` windows), the **annotations** (`PathRef.lengthHint`,
`SpaceMention.sizeHint`, a declared `SpatialEnv` input type), and **derivation** (the transfers, the
certified relational laws, the solver). An earlier revision seeded closed subterms by evaluating them
(`groundFold`, in all three tiers); it was removed, and the exactness it produced on the cornerstones
went with it. Anything that looks exact now is derived.

## 1. The domain

| Level | Carrier | Order |
|---|---|---|
| Counts | `Cnt = ℕ ∪ {∞}` | `≤`, total, `0` least, `∞` greatest |
| Class | `Ivl = Cnt × Cnt` (a count interval) | `a ⊑ b ⟺ lo b ≤ lo a ∧ hi a ≤ hi b` (inclusion) |
| Type | `len ⇀ Ivl` (+ one spill bucket) | pointwise `⊑` |

`∞` is a **datatype constructor**, not a sentinel integer — the count domain is genuinely complete,
which is what makes `⊤ = [0, ∞]` a real greatest element rather than an arithmetic accident.

**⊥ is the inconsistent interval `(∞, 0)`** — "no count is possible", i.e. the provably-empty
marker `LenBounds.empty`. This is *not* `[0,0]`: γ([0,0]) = {0} ⊄ γ([2,5]), so `[0,0]` is an ordinary
element meaning "this class is empty". The first draft claimed `[0,0]` was ⊥ and **z3 refuted it**
(`lat_ivl_bounds`); the certificate now proves the corrected statement *and* the refutation of the
old one. This is why `LenBounds.empty = (INF, 0)` composes correctly through `min`/`max`.

## 3. Arithmetic the transfers run on (certified: `lat_sat_*`)

| Property | File |
|---|---|
| saturating `+`: commutative, associative, ∞-absorbing, monotone | `lat_sat_add` |
| saturating `×`: commutative, **0 beats ∞**, monotone | `lat_sat_mul` |
| relu `−`: non-negative, `≤` minuend, **monotone DOWN in the subtrahend** | `lat_sat_sub` |
| `0 ≤ a ≤ b, 0 ≤ c ≤ d ⇒ a·c ≤ b·d` (the nonlinear core, factored out) | `lat_mul_mono_int` |

`0 beats ∞` is the `Ivl.mul` convention: an empty class times anything unknown is still empty.

## 4. What licenses the analysis (certified: `lat_transfer_*`, `lat_postfixpoint`)

- **Monotonicity of every per-class transfer** — `lat_transfer_mono_binary` (∪, ∩, ∖),
  `lat_transfer_mono_unary` (restriction kill/keep, tails), `lat_transfer_mono_scale`
  (iteration/fold scaling). This is the precondition for the fixpoint iteration to make sense.
- **Local soundness** — each transfer's interval contains the true class count, given the concrete
  per-class facts (`lat_transfer_sound`).
- **POST-FIXPOINT theorem** (`lat_postfixpoint`, via an explicit nat-induction schema):
  `F#` monotone ∧ `init ⊑ T` ∧ `F#(T) ⊑ T` ⇒ every Kleene iterate `⊑ T`. **This is the theorem the
  `Fixpoint` transfer rests on** — the analysis checks exactly those two premises and falls back
  when the check fails, so this certificate is what makes that fallback logic principled rather
  than hopeful.
- **Widening soundness** (`lat_widen_sound`): count-widening and class-spilling only ever loosen.
- **Projection monotonicity** (`lat_proj_mono`): a tighter type gives tighter size *and* length
  bounds; disjoint classes add.
- **MEET-DOMINATES** (`lat_meet_dominates`): meeting two sound intervals stays sound and is at
  least as tight as either — the theorem behind `bestSize`/`bestLen`.
- **Galois connection** (`sp_galois`): `c ∈ γ(α c)` and `c ∈ γ(t) ⇒ α(c) ⊑ t`, i.e. `α∘γ ⊑ id`.

## 5. Concrete path facts each transfer needs (certified: `sp_*`)

| Fact | File | Used by |
|---|---|---|
| `len(p·q) = len p + len q` (induction schema) | `sp_len_append` | wrap/composition class shifts |
| `len p ≥ 0`; `isPrefix p q ⇒ len p ≤ len q` (induction) | `sp_len_nonneg`, `sp_isprefix_len` | the restriction cut-off |
| **restriction annihilates** classes shorter than the shortest prefix | `sp_restrict_annihilate` | `Restriction` transfer |
| **raffination keeps those classes exactly** | `sp_raff_exact` | `Raffination` transfer |
| `x<\|y` ⊎ `x\\|y` partition `x` (disjoint + covering) | `sp_partition_restrict_raff` | the exact-sum union case |
| length-disjoint sets have **empty** meet | `sp_lendisjoint_meet` | `Intersection` → provably empty |
| wrap is an injective length-shift (⊇) and produces nothing else (⊆) | `sp_wrap_into`, `sp_wrap_onto` | `Wrap` = exact class shift |
| unwrap / tails shift classes down; a nonempty class yields ≥1 tail | `sp_unwrap_shift`, `sp_tails_shift` | `Unwrap`, `TailsUnion` |
| composition adds lengths with a witnessing pair | `sp_comp_additive` | class-pair convolution |
| composition is injective for a fixed left factor | `sp_comp_inject` | the per-class **lower** bound |
| **composition collides across class pairs** | `sp_comp_collision` | why that lower bound is a **max, never a sum** |
| iteration group keys have length exactly 1 | `sp_iter_head_one` | the head-binder `lengthHint` |
| per-class ∪/∩/∖ bounds from the measure axioms | `sp_class_bounds` | `Union`/`Intersection`/`Subtraction` |

**The cardinality bridge** is four standard finite-set axioms — inclusion–exclusion, meet ⊆ both,
`x∖y = x` minus the meet, non-negativity — asserted explicitly and marked `DEFINITIONAL` in the
registry. Everything above and below that line is proved *from* them; nothing else is assumed.

## 6. Laws that made the analysis stronger

These began as "laws I suspect hold" and became code once certified.

1. **Subsumption family** (`sp_subsume_syntactic`, `sp_subsume_ops`): `∩`, `∖`, `<|`, `\|` are all
   ⊆ their left operand and each operand ⊆ their union; and `y ⊆ x` implies `x ∪ y = x`,
   `x ∩ y = y`, `x ∖ y` exact. Implemented as `SpatialTypes.subsumes` + relational cases in the
   transfer — this kills the double counting a pure count domain suffers on `x ∪ (x ∩ y)`, the
   exact shape where `SizeZ3`'s relational facts used to beat the spatial analysis.
2. **Partition** (`sp_partition_restrict_raff`): `(x<|y) ∪ (x\|y)` is `x` *exactly*, per class —
   the per-length analogue of `SizeZ3`'s `partitionPair`.
3. **Self-restriction** (`sp_restrict_self`, `sp_isprefix_refl`): `x <| x = x` and `x \| x = ∅`,
   because every path is its own prefix.
4. **Inclusion–exclusion is strictly stronger** than the additive union bound whenever the classes
   overlap (`sp_class_ie_tighter`) — the formal statement of the remaining gap in §7.

Measured effect on 3000 closed corpus instances: strictly tighter than tier-1 on **1480** for size
(was 1308) and **87** for length (was 60).

## 7. Known limits (honest)

- **Sibling overlap.** The domain has no per-class *meet* variable, so `|a ∪ b| ≤ |a| + |b|` cannot
  become inclusion–exclusion unless subsumption is syntactically visible. On 2/150 corpus programs
  `SizeZ3` is therefore strictly tighter; `bestSize` meets both (§4) so consumers lose nothing.
- **The single spill bucket loses headedness.** Once classes spill into `rest`, "some path here has
  length ≥ 1" is no longer per-class, so a tails lower bound can only fire when *every* length in
  the bucket is headed. Adding a `loHeaded` component (as `SizeBounds` has) would recover it.
- **Closed terms are not evaluated.** A fully-ground subterm still gets only what the transfers
  derive, by the §0 invariant — so e.g. the expanded aunt query is `[0, 84]`, not the true `3`. The
  way to tighten a closed term is a better transfer or a solver fact, never a fold.
- **Widening is not proved terminating.** Spilling and count-widening are proved *sound*
  (`lat_widen_sound`); the ascending-chain argument (finite classes × bounded lengths) is
  structural, not certified.
